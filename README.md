📊 Sales Analysis Dashboard (Excel)
Overview

This project is an interactive Sales Analysis Dashboard built in Microsoft Excel to analyze sales performance, profitability, customer distribution, and product performance.

The dashboard provides a clear overview of key business metrics and helps identify trends, high-performing categories, and areas for improvement through interactive visualizations and filters.
